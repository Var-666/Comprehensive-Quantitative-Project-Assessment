# 第一阶段验收基线

确认日期：2026-10-20。确认来源：本聊天中用户明确回复“采用上述规则作为第一阶段验收基线”。这份确认只覆盖下列条目，不扩展为后续提醒、财务或评价规则的批准。

1. 项目编号全局唯一；节点编号在所属项目内唯一。只校验非空、字段长度和唯一性，不编造编号格式。
2. Excel 导入遇错整批不写业务数据；重复编号不覆盖。预览不写业务表，确认时二次验证，幂等提交防重。部分成功选项禁用。
3. 计划编制人与批准人分离。创建版本、增加节点、修改节点计划均把当前用户计入版本编制人员；任何编制人员不能批准该版本。
4. 实际记录提交人与核实人分离；待核实记录不替换当前已核实事实。
5. 按项目分配 admin / editor / reviewer / viewer 角色。admin 可编辑、审核和分配项目成员，但仍受自审禁令约束；editor 可编辑；reviewer 可读取、批准和核实；viewer 只读。

系统管理员是账号配置与项目初始化操作角色：可以新建/导入项目、配置项目成员，但不会自动获得未授权项目的业务读写权限。新项目创建人自动获得该项目管理员角色。账号初始化通过本机运维命令，不提供开放注册或默认密码。

登录、密码哈希、会话期限、CSRF 与项目访问控制属于技术实现；会话有效期默认8小时，密码采用 pwdlib 的 Argon2 实现，Cookie 为 HttpOnly/SameSite=Strict。HTTPS 部署时须开启 Secure Cookie。正式企业的人员目录、SSO、附件来源和部署域名仍由企业配置，不以测试账号或模拟记录冒充。

第一阶段的完成标准是原请求中的工程、项目 CRUD、节点与版本管理、Excel 导入、样本初始化、自动化测试及启动文档，另包含本轮确认的权限与独立审核要求。工作日历、自动提醒、财务和 AI 属于后续阶段，不纳入本次完成判定。
